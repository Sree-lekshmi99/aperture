Mandatory first expansion with exact span citations

val:SciBench_gpt-4o-mini_llm_debate_29_4444d10c

Same model, temperature 0, JSON response format, 2,000-token output cap, system prompt and citation requirements in all arms. Short context keeps 180 characters per event. Mandatory first expansion requires an investigator-selected expansion before targeted diagnosis when the overview is clipped. This is not learned retrieval. Limits: five events per round, two rounds; 12,000 input tokens including instructions and a 256-token framing reserve, of which at most 10,000 are evidence. The gate has no policy switch.

The model returns chunk_id + span_id. Exact quotations are attached by application code from the received-evidence log registered after clipping and token-budget enforcement. Cross-author evidence is allowed. Provenance does not establish attribution correctness.

Limits and persistence

  • Single S4 example, one session per arm; no general accuracy conclusion.
  • The gate verifies citation provenance, not whether a quotation logically proves the claim.
  • Mandatory first expansion is a fixed protocol rule, not learned retrieval. The investigator chooses events without label access.
  • All round inputs and outputs count toward usage, including provisional and rejected claims.
  • Prompt and evidence framing now require citations; these results are not identical-prompt reruns of the old baseline.
